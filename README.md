# KitaGuard PH 🇵🇭
**100% Offline Daily Kita (Profit) & Utang (Customer Credit) Tracker for Filipino Micro-Earners**

🔗 **Live App:** [https://ujjainmahaakaal-dev.github.io/kitaguard-ph/](https://ujjainmahaakaal-dev.github.io/kitaguard-ph/)

---

## 📖 Overview
**KitaGuard PH** is a zero-data, single-file mobile web utility built for tricycle and jeepney drivers, *palengke* (wet market) vendors, and *sari-sari* store owners in the Philippines. 

Daily earners frequently mix their working capital (*puhunan*, fuel, or vehicle *boundary*) with household cash—leading to capital shortfalls the next morning—and lose track of informal customer credit (*utang*). KitaGuard PH solves this with a fast, offline-first pocket ledger that requires **zero app store downloads, zero logins, and zero mobile data** after the first load.

## ✨ Key Features
* **Protects Tomorrow's Capital (*Puhunan / Boundary*):** Instantly separates untouchable operating capital and daily expenses from true take-home profit (*Malinis na Kita*).
* **Shortfall Warnings:** Alerts the user immediately if daily cash collected falls below tomorrow's required *boundary* or restock capital.
* **Built-In *Utang* Ledger:** Tracks unpaid customer tabs, displays total trapped credit, and marks debts as paid (*Bayad Na*) in one tap.
* **1-Tap WhatsApp / SMS Reminders:** Generates a polite Taglish payment reminder message ready to copy or share directly with customers.
* **Bilingual Interface (Taglish / English):** Switches seamlessly between natural Taglish and English.
* **100% Private & Offline:** All financial logs are stored locally on the user's phone via browser `localStorage`—no cloud servers, no tracking, and works even with zero signal or load.

## 📱 How to Use (For Drivers & Vendors)
1. Open the live link once on your phone browser (Chrome or Safari):  
   **`https://ujjainmahaakaal-dev.github.io/kitaguard-ph/`**
2. Tap your browser menu (**⋮** on Android Chrome or **Share** on iPhone Safari) and select **"Add to Home Screen"**.
3. Use it anytime—even completely offline—to log daily cash collected, reserve tomorrow's *puhunan*/fuel, and track *utang*.

## 🛠️ Tech Stack
* **Architecture:** Single-file HTML5, CSS3, and Vanilla JavaScript (zero external libraries or APIs).
* **Storage:** Client-side `localStorage` for instant offline persistence.
* **Hosting:** GitHub Pages.
